# Codex 个人研发提示词模板

> 使用方法：复制所需模板，把 `【】` 替换为实际内容。每个模板已内置任务分类、规则来源、执行约定和对应验证方式，可直接作为一条完整提示词使用。

## 0. 默认执行约定

以下约定已完整放入每个可复制模板；请按本轮任务分类执行。规则可来自现有 README、PRD、团队规范或会话要求，不需要新建规则文件。Skill 的默认保存、提交或执行步骤不能扩张本轮授权。

```text
本轮任务分类：【只读分析 / 文档草案 / 本地实施 / 本地验证 / 证据整理】
规则来源（仅填写现有资料）：【本轮用户要求；现有 README、PRD、团队规范、已确认方案的准确路径；没有则填无】
首轮先复述已经实际读到的规则来源、适用目录和关键约束；未读或无法访问的来源明确列出，不假装已读，不为补规则创建 AGENTS.md 等规则文件。

执行约定：
- 修改业务代码、测试、调试脚本或其他实施文件前，默认先确认方案，再单独确认实施与验证计划。仅对单仓局部可逆、需求无歧义，且不改变公共契约、表结构、依赖、权限、安全或事务语义的小任务，可同时展示短方案、准确文件范围、非目标和验证计划，由我明确一次批准方案与计划；不得自行省略确认。已有批准在其范围内持续有效，不重复请求相同确认；范围或条件改变时再核对。
- 文档草案默认只在对话输出；若本轮请求已给出准确保存路径，并明确要求生成或保存该文档，即视为“仅保存这些文档”的授权，不重复询问。未具备此授权时，先列准确路径再等待明确授权。此授权不包括代码、测试、调试脚本或新增代码执行，也不代表批准实施；只读分析、交接或报告任务的文档保存不扩张为实施任务。
- 不创建 AGENTS.md 等规则文件；保留已有用户修改，不覆盖、回滚或删除；发现资料冲突、需求缺失、范围越界或会改变业务结果的假设时停止，一次只问我一个关键问题。
- 外部系统只允许本任务明确提供或授权的只读资料读取；不得连接或写入任何数据库，不得执行外部写入、发送、上传、删除或状态变更；即使我确认，也只能生成脚本、风险说明和人工步骤。
- 不执行 git commit、git push，不创建、编辑、评论、审批、合并、关闭、重开或进行其他 PR 变更；不部署、不发布、不修改线上配置，不使用或输出真实密码、Token、Cookie、生产 DSN 和敏感数据。
- 结论须对应本轮实际证据；未读取、未执行、未验证或证据已失效时明确说明，并报告剩余风险。不把局部测试通过概括为所有场景无竞态或无事务问题。
- 验证按本轮任务分类选择：只读分析和文档草案核对内容与静态证据；本地实施或明确验证任务才运行审查过的必要本地检查；交接和报告只整理已有结果，不新增执行。
- 运行代码前检查入口、初始化、脱敏配置、环境变量名、网络和工具行为；无法排除数据库、外部系统或敏感数据副作用时不执行。不自行下载依赖或 toolchain、安装工具或启动服务。
- 报告证据来源、实际执行范围、未验证项和剩余风险；没有执行就明确写未执行。局部测试通过不能证明所有场景无竞态或无事务问题。
```
