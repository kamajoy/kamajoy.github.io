# 启动模板(复制 → 填空 → 发送)

## ① 全流程(实现 PRD 新功能)
```
/prd 模式:全流程
项目/模块:
接口:(路径 + 示例参数)
返回字段位置:(如 responseData.xxx.list)
TRD:
PRD:      章节/功能点:
本次范围(做):
不做 / 已实现:
已知规则(可选,计算公式/生效条件/位置/文案):
```

## ② 完整性检查
```
/prd 模式:检查
项目/模块:
接口:
TRD:
PRD:      章节/功能点:
重点关注(可选):
```

## ③ 修 Bug
```
/prd 模式:修Bug
项目/模块:
接口:
PRD:      章节/功能点:(可选,用于判断是否偏离需求)
现象:
期望:
复现参数/入参:
报错/日志(可选):
```

## ④ 需求逻辑调整
```
/prd 模式:调整
项目/模块:
接口:
PRD/TRD:(原文档,可选)
旧规则:
新规则:
变更原因(可选):
```

## 过程中你只需要说的话
| 场景 | 回复 |
|---|---|
| AI 提问,选建议项 | `A` |
| 通过当前关卡 | `确认` |
| 觉得分析有偏差 | `重新分析` |
| 需求很明确,不想多问 | `跳过分析` |
| 想先只看不改 | `只读` |
| 编码完想核对 | `只检查` |
| 忘了当前进度 | `列清单` |
