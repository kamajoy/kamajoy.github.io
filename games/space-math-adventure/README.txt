太空数学闯关 - 使用说明

1. Windows、Mac 电脑
   双击 index.html，即可用默认浏览器开始游戏。

2. 联想 Pad / 安卓平板
   推荐将整个 space-math-adventure 文件夹发布到静态网站，然后用平板浏览器访问网址。
   在浏览器菜单中选择“添加到主屏幕”，以后可以像普通应用一样打开，并支持离线使用。

3. 发布为 Web 网页
   将本文件夹中的全部文件原样上传到任意静态网站空间即可，不需要数据库和服务器程序。

4. 学习记录
   关卡、积分、星星和练习记录保存在当前设备的浏览器中，不会上传到网络。
   更换浏览器、清除浏览器数据或点击游戏内“清空本机学习记录”会重置进度。

建议浏览器：Chrome、Edge、Safari 或联想浏览器的较新版本。
