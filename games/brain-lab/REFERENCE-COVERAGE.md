# 参考资源覆盖清单

本项目不复制第三方网站题目、角色、图片、音频或品牌素材。题目均为本站原创，参考的是公开教育产品的课程结构、互动方法和能力目标，适合离线静态网页运行。

| 参考资源 | 本站对应内容 | 覆盖状态 |
|---|---|---|
| Khan Academy | 数字找朋友、四则运算、数独、购物、时间、测量、科学实验 | 完整覆盖数学与科学分级练习方法 |
| Scratch | 角色事件编程、广播协作、互动故事、创意画本 | 已补齐事件、角色和创意表达 |
| Code.org | 指令编程迷宫、循环与条件、程序调试 | 已补齐顺序、循环、条件和调试 |
| NRICH Primary | 规律、逻辑表格、多条件推理、开放谜题、纸笔探索 | 完整覆盖多策略数学推理 |
| Mathigon | 动态几何实验、图形旋转、对称、折纸、立体计数 | 已覆盖探索式几何与空间思维 |
| GeoGebra | 坐标变换、平移、反射、旋转、角度与面积不变量 | 已补齐坐标和几何实验 |
| ChessKid | 国际象棋走法、王的安全、交换、牵制、双重攻击和残局计划 | 已补齐分级棋局策略 |
| NASA Space Place | 太阳系、月相、航天服、卫星、火星和地球环境 | 已补齐航天与地球科学主题 |
| 国家中小学智慧教育平台 | 中文字词、阅读表达、数学、科学、生活安全与综合素养 | 完整覆盖中文基础学科巩固 |
| Duolingo | 英语词汇听辨、短句听力、语序、语法、阅读理解 | 已补齐英语听读和渐进练习 |

新增活动均使用四级难度，每轮 12 题。答对题目的稳定 ID 会存入浏览器 `localStorage`，后续练习自动排除；答错题仍会在未来轮次中出现。
